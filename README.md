This project's OV7670 reading is based on indrek's LiveOV7670 code. 
The python backend processes the output from the OV7670 and saves any instance of a face being recognized locally
All the SCCB registers and I2S clock timings have been taken the same as indrek's so his code can be directly pieced with this backend and recognition
